# Escuela de Danza de Alboraya — Web

Sitio web oficial de la Escuela de Danza de Alboraya. Incluye información sobre las disciplinas impartidas, horarios, precios, contacto y más.

## 🛠 Tecnologías

- **Angular 21** (standalone components)
- **TypeScript**
- **CSS** (sin frameworks)
- **Google Fonts** (locales en `assets/fonts`)

## 📋 Requisitos

- Node.js (versión 20 o superior)
- npm (incluido con Node.js)
- Angular CLI: `npm install -g @angular/cli`
